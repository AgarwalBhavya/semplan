# SEM Plan Automation

This project automates the creation of Google Ads campaign structures in JSON format based on user input.  
It helps generate campaigns, ad groups, and keywords efficiently.

## Features

Interactive command-line prompts to enter:
- Campaign Name
- Ad Groups
- Keywords

Clean, well-organized output files ready to use in SEM workflows.


## How to Run

1. **Clone the Repository**

   ```bash
   git clone https://github.com/AgarwalBhavya/semplan.git
   cd semplan

2.  **Install the Dependencies**
   pip install -r requirements.txt

3.  **Run the script**
   python main.py
